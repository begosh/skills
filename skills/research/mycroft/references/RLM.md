# RLM — External-context investigation

Use this mode when a large or dense corpus benefits from programmatic inspection and bounded semantic calls. It governs work within an enquiry; Triad governs independent questions.

## Bind

Keep the corpus outside the model prompt. Freeze its identity, extraction/span conventions, enquiry objective, completion criterion and allocation. Identify readable external evidence, code execution with retained results and a usable semantic-call route.

A host may alternate code and model/agent calls; an existing qualified library is optional. Bind access and scheduling through [HOST.md](HOST.md).

**Ready:** The actual corpus, execution/state and semantic-call facilities are usable. Otherwise use ordinary corpus research and report the unavailable mechanism.

## Inspect, ask and aggregate

1. **Inspect:** Run code to select spans, transform records or calculate aggregates. Return bounded observations; retain bulky text/arrays externally.
2. **Ask:** Where interpretation is needed, send selected evidence and one semantic question through the available call route.
3. **Retain:** Store each answer with source ID/span, status and material gap. Check child assertions against support.
4. **Aggregate:** Use code to join evidence, reconcile classifications or calculate results. Verify key conclusions against originals and conflicts.

Iterate for material gaps within the remaining allocation. State whether the implementation is host-driven or library-based, and whether retained results live in a REPL or files. Chunk summaries alone establish summarization, not this full mechanism.

An ordinary semantic child reads selected evidence; a recursive child performs another external-context loop. Start shallow and use HOST's native-depth controls. Observe iterations, semantic calls, depth and work as available.

**Enquiry complete:** The bounded question has checked source-linked findings, or an explicit partial status with unmet evidence. The record identifies actual inspection, calls and aggregation.

## Records and comparison

Use the [case record](EVIDENCE.md#records-and-continuation) for corpus identity, enquiries, accepted findings and next steps; retain RLM working state separately when needed. Verified source identity and completed scope govern reuse.

Compare native and RLM modes on matched sources, quality criteria and allowances. Report observed answer quality, failures, calls and latency; qualify transfer to other models/tasks.

## Primary evidence

[Recursive Language Models, v1](https://arxiv.org/html/2512.24601v1), §1/Figure 2 and §2.2, describes the external environment, programmatic inspection and semantic subcalls. §2.2 includes a no-subcall ablation; §5 reports depth-one experiments with ordinary LM children and runtime/cost limits.

Host-driven scheduling, project-local records and evidence contracts are this skill's adaptations.
