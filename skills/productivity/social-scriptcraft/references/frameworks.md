# Dramaturgiska Modeller & Retention-Ramverk för Social Video

Detta dokument sammanfattar de mest effektiva dramaturgiska modellerna och retention-strategierna för att skapa virala, engagerande och konverterande videomanus.

Tider, talhastigheter och klippintervall är redaktionella utgångspunkter. Anpassa dem efter användarens brief och kreatörsprofil; de är inte empiriska garantier för algoritmisk räckvidd. Hook-exemplens siffror måste ersättas med verifierade belägg innan publicering.

---

## 1. Plattformsspecifika Dramaturgiska Motorer

### A. Shorts / TikTok / Reels (15–60 sekunder)
**Primär modell:** Hook - Story - Offer (HSO)  
**Sekundär modell:** Micro-PAS (Problem - Agitate - Solve)

```
0s ────── 3s ──────────────────────── 50s ──────── 60s
│   HOOK    │       MICRO-VALUE        │   LOOP / CTA  │
│ Mönster-  │ Konkret insikt eller     │ Sömlös loop   │
│ brytande  │ demonstration utan död-  │ tillbaka till │
│ A/V-chock │ tid eller transport      │ startsekvens  │
```

* **Genomsnittlig klipplängd (ASD):** 1.2 – 2.2 sekunder.
* **Talhastighet (WPM):** 160 – 190 ord per minut (hög densitet, alla pauser klipps bort via J/L-cuts).
* **Loop Retention Index (LRI):** Videons sista mening ska grammatiskt eller tematiskt leda direkt in i start-hooken, vilket gör att videon repeteras utan märkbar skarv (>100% genomsnittlig visningstid).

---

### B. YouTube Långformat (8–20 minuter)
**Primär modell:** Hero's 5-Act Mystery Box  
**Sekundär modell:** Multipla Open Loops

```
0:00 ─── 0:30 ─── 2:00 ───────────────────── 12:00 ─── 15:00
  │ STINGER │ INCITING │  RISING ESCALATION   │ CLIMAX  │ SOFT-BRIDGE
  │ Insats  │ Friktion │  Open loops öppnas/  │ Kärn-   │ Nästa video
  │ & Open  │ & Status │  stängs sekventiellt │ insikt  │ UTAN 'Tack'
  │ Loop    │ Quo fall │  (RRI: 45-60s)       │ Payoff  │
```

* **30-sekundersregeln:** Inga kanallogotyper, hej-fraser eller presentationer under de första 90 sekunderna. Första 30 sekunderna måste visuellt bevisa hookens löfte.
* **Retention Reset Interval (RRI):** Var 45–60:e sekund måste ett sensoriskt mönsterbrott ske (ny vinkel, skärmgrafik, SFX, hypotetiskt scenario, ny fråga).
* **Open Loop Chains:** Öppna alltid en ny fråga innan den föregående besvaras helt.

### C. LinkedIn & B2B Video (45–120 sekunder)
**Primär modell:** Problem - Agitate - Solve (PAS)  
**Sekundär modell:** Before - After - Bridge (BAB)

```
0s ────── 5s ────────────── 30s ───────────────────── 95s ─── 120s
│ B2B HOOK  │     AGITATE      │       ACTIONABLE        │ DEBATT-  │
│ Kostsamt  │ Vad inaktivitet  │       FRAMEWORK         │ FRÅGA    │
│ misstag   │ kostar i pengar  │ 3-stegs implementerbar  │ Skapa    │
│ & tes     │ eller tid        │ lösning                 │ kommentar│
```

* **Silent Playback Optimization:** Gör budskapet begripligt utan ljud. Visa nyckelbegrepp som text/lower-thirds.
* **Talhastighet (WPM):** 130 – 150 ord per minut (deliberat och auktoritativt).
* **Kommentars-motor:** Avsluta inte med 'Ladda ner mitt whitepaper', utan ställ en polariserande branschfråga vid $T = 75\%$ för att driva kommentarer.

## 2. Hook Vault: Psykologiska Vinklar

| Trigger-typ | Hook-formel | Exempel |
| :--- | :--- | :--- |
| **Negative Bias / Förlust** | *"Sluta göra [X] innan det kostar dig [Y]."* | *"Om du fortfarande skriver kod utan AI-agenter förlorar du 4 timmar varje dag."* |
| **Konträr Sanning** | *"Branschen ljuger om [X]. Här är vad som faktiskt händer."* | *"Du behöver inte 10 000 följare för att sälja för en miljon. Här är matematiken."* |
| **Hög Transformation** | *"Hur jag gick från [Dåligt läge] till [Drömläge] på [Kort tid]."* | *"Hur jag automatiserade hela min bokföring på 14 minuter med en lokal skriptkedja."* |
| **Mysterium / Open Loop** | *"Det finns en anledning till att de smartaste [Målgrupp] aldrig [Gör X]..."* | *"Det finns en anledning till att OpenAI just gjorde den här ändringen..."* |
| **Omedelbar Demonstration** | *[Visuell handling direkt utan ord under de första 2 sekunderna]* | *Kamera zoomar in på en terminal som kompilerar en hel app på 3 sekunder.* |

## 3. A/V-Regler & Pacing

1. **A-Roll (Talet):**
   - Skriv för tal, inte läsning. Korta meningar (max 12–15 ord).
   - Använd fonetisk rytm: variera mellan korta punchlines och sammanbindande förklaringar.

2. **B-Roll (Visuellt stöd):**
   - B-roll ska aldrig vara generisk bakgrundsvideo. Den ska bekräfta, illustrera eller ironisera det som sägs i talet.
   - Ange kamerarörelser: `Push-in` vid allvar/betoning, `Snap-zoom` vid överraskning, `Pan` vid listor.

3. **SFX & Text (Sensorisk förstärkning):**
   - Använd diskreta ljudeffekter (woosh, click, glitch, sub-bass drop) synkroniserat med viktiga ord.
   - Kinetisk text: Lyft fram 1–3 nyckelord per mening i versaler med avvikande accentfärg.
